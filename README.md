# КОНВЕРТР ВАЛЮТ

## Описание

Это скрипт на Python который делает запрос благодаря библеотеке requests на [сайт](https://www.exchangerate-api.com/) и конвертирует заданную валюту в итоговую.

## Как установить

Python3 должен быть уже установлен. Затем используйте pip (или pip3, есть конфликт Python2).

```
pip install -r requirements.txt
```

Перейдите на [сайт](https://www.exchangerate-api.com/) и получите api token.

В папке с проектом не забудьте содать .env файл, где вы укажите ваш собственный токен.
```
TOKEN=ваш токен с сайта
```

Создайте и активируйте виртуальное окружение (опционально, но рекомендуется):

```
python -m venv venv
```

```
source venv/bin/activate
```

## Запуск

Для запуска скрипта введите в командной строке:

```
python main.py base target amount
```

* base — базовая валюта подробнее с возможными валютами можно ознакомится на [сайте](https://www.exchangerate-api.com/docs/supported-currencies)
* target — итоговая валюта
* amount — введите количество базовой валюты

Пример:

```
python main.py RUB EUR 15000
```
