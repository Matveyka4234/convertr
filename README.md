# КОНВЕРТР ВАЛЮТ

## Описание

Это скрипт на Python который делает запрос благодаря библеотеке requests на [сайт](https://www.exchangerate-api.com/) и конвертирует заданную валюту в итоговую.

## Как установить

Python3 должен быть уже установлен. Затем используйте pip (или pip3, есть конфликт Python2).

Установите библиотеки: requests, argparse и dotenv.

## Запуск

Перейдите на [сайт](https://www.exchangerate-api.com/) и получите api token, для этого зарегистрируйтесь скопируйте свой api-key и вставьте его в файл .env.

И запустите скрипт с помощью команды:
```
main.py
```
